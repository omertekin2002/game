# Systems and numbers

The game bible's file for **how the game works**: realms, portals and variant realms; the save plan (v7-v11); the
condition language and the flag dictionary; dialogue, scenes, quests, Hoot's Field Notes and "Ask the Tree"; items,
tools, abilities and gate objects with their numbers; travel (the chart, benches, root-gates, the *Dandelion*); beacons
and crown lanterns; NPC schedules; collectible kinds and counts; hearts; completion rows; the economy ledger; and the
test harness. Written 2026-11-21 against `main` at `b79d73d` (save v6), from `CANON.md`,
`INDEX.md`, `ground/ENGINE.md` and `CANON-NOW.md`.

**Order of authority.** `CANON-NOW.md` LOCKED items > `CANON.md` > this bible > `INDEX.md` > a step issue. Where
this file decides something CANON left open, it is listed in [Decisions made here](#decisions-made-here).

**What this file does not own** (link, never copy): the text of lines, letters, logs and scenes
([lore.md](./lore.md), [story.md](./story.md), [side-content.md](./side-content.md)); where things stand on a map
([atlas-home.md](./atlas-home.md), [atlas-isles.md](./atlas-isles.md), [atlas-far.md](./atlas-far.md)); room layouts
([dungeons.md](./dungeons.md)); enemy and boss numbers ([creatures.md](./creatures.md)); character looks and per-NPC
schedules ([cast.md](./cast.md)); the style preamble, the brief template, music and SFX
([art-audio.md](./art-audio.md#style), [art-audio.md#brief-template](./art-audio.md#brief-template)); tone, the verb
list, invariants and budgets ([charter.md](./charter.md#tone), [charter.md#invariants](./charter.md#invariants),
[charter.md#budgets](./charter.md#budgets)).

**Conventions used below.**
- `S` is the save state (`game.S`), `W` the loaded World (`G.world`), `EV` the event bus names in `js/events.js`.
- Time: `hour = S.tod × 24`. A day is `CFG.dayLength` = 480 s, so **one game hour = 20 s** of play.
  Named bands come from `nightAmount(h)` in `js/sky.js`: **day** 07:12-17:24, **dusk** 17:24-19:48, **night**
  19:48-04:36, **dawn** 04:36-07:12.
- Distances in metres, times in seconds, gems as integers. "Half a heart" = 1 HP.
- `STYLE` in an image prompt means the image-prompt preamble of [art-audio.md#style](./art-audio.md#style), pasted in
  front of the prompt. Every generated image is original; never imitate another game's characters or art.
- Every ART BRIEF below has the fields of [art-audio.md#brief-template](./art-audio.md#brief-template): silhouette,
  size, palette, materials, pose or animation, poly budget, image prompt, 3D prompt, manifest key, procedural fallback.

## Realms

A **realm** is one loadable World: its own seed, grid size, generator recipe, palette, music, regions, NPCs, enemy
table and anchors. Only one realm is active at a time, plus at most one resident parent. The game becomes large
through many realms, never through one huge streamed world (ENGINE §2). Home (`home`) is today's island, generated by
today's untouched `generateWorld(7151)`.

Rules for every kind:
- An overworld follows the land grammar in [charter.md#invariants](./charter.md#invariants) and CANON §5.1: 4 regions
  with name cards (home 5), one landmark per region, one keepsake behind every landmark, one town region with no
  enemies, an arrival spawn, 4-6 benches, one root-gate (sky lands excepted, see [Root-gates](#root-gates)), at least
  one point of interest per 1,250 m² of land, and the 40 × 40 m coverage test ([test harness](#coverage-test)).
- Budgets per view (both cameras): main pass ≤ 200 draw calls, total ≤ 300 (hard cap 350); ≤ 1.3 M triangles;
  generation ≤ 1.2 s on desktop (`W.genMs`); ≤ 24 instanced prop types and ≤ 12 new material programs per realm;
  bundle ≤ 2.5 MB without GLBs. See [charter.md#budgets](./charter.md#budgets).
- Every realm's prints are frozen in `tests/fixtures/realm-prints/<id>.json` by the PR that first generates it; after
  it is unhidden, only post-passes on their own RNG add to it.

### The realm registry

`js/realms/index.js` exports `REALMS` (pure data) and `generateRealm(id, o)`. One entry per realm:

```js

  id: 'duskwick', name: 'Duskwick', kind: 'overworld', size: 448, seed: 40211, recipe: 'lagoon',
  palette: 'duskwick', music: 'duskwick', ambience: 'duskwick',
  hidden: true,                 // until the step that ships its main quest sets it false
  open: 'flag:ch7',             // condition: the chart may list it (see #conditions)
  parent: null,                 // resident parent realm id (interiors, dungeons, variants)
  variantOf: null,              // parent realm id for kind 'variant' (same seed + generator)
  spawns: { jetty: {x, z, facing}, rootgate: {...}, tower: {...} },   // filled by the recipe; ids listed here
  arrive: 'jetty',              // default spawn when sailing in

  bundle: 'duskwick',         // PWA bundle id (assets/realms/duskwick/)
```

<a id="realm-swap"></a>

### Swapping realms

`js/realms/manager.js` `RealmManager.enter(id, spawnId, how)` runs, in order (ENGINE §2.3):

| # | Step | Time budget (desktop) |
|---|---|---|
| 1 | input lock; fade to the loading colour | 0.35 s |
| 2 | show the card: the realm's painted loading card ([art-audio.md#loading-cards](./art-audio.md#loading-cards)); for chart sailing the sailing card, held **4.0 s minimum, 6.0 s maximum** unless generation is slower | - |
| 3 | autosave (`S.realm = { id, spawn }`) | < 5 ms |
| 4 | `teardown(current)` unless it becomes the resident parent | < 120 ms |
| 5 | `Assets.loadRealm(id)` (lazy bundle; missing keys fall back to procedural) | network |
| 6 | `generateRealm(id)`; reuse the resident parent with no generation when returning to it | ≤ 1.2 s; < 100 ms back to a resident parent |
| 7 | build terrain, water, Scenery; `modules.onWorld(W, prev)`; warm up the realm's new materials only | ≤ 0.5 s |
| 8 | place Pip at the spawn on walkable ground, facing `spawn.facing`; restore the boat if `S.boat.realm === id` | - |
| 9 | fade in 0.35 s; region card of the arrival region; `EV.REALM { id, prev, spawn, how }` | 0.35 s |

Rules: at most two realms resident (the active one and its parent). Leaving an interior, dungeon, Hollow or variant
always returns to its parent at the portal's paired spawn. A realm swap never happens during a fight, a scene, a
boss intro or while airborne; a walk-in portal waits until Pip is grounded. `RealmManager.mode = 'reload'` is a
debug-only fallback, never shipped.

<a id="dizzy-rules"></a>

### Dizzy and falling per realm

"Pip got dizzy!" stays the only failure; full hearts, gems kept, nothing lost. Where he wakes:

| Realm kind | Pip wakes | Toast (second line after "Pip got dizzy!") |
|---|---|---|
| home | by the Great Tree (LOCKED) | "Pip woke up by the Great Tree." (LOCKED) |
| other overworld, cavern, floating, sky | at the last bench sat on in this realm, else the arrival spawn | "Pip woke up by the bench." / "Pip woke up on the jetty." / "Pip woke up by the root-gate." |
| sea (on an islet) | the nearest docking spot, aboard the *Dandelion* | "Pip woke up in the *Dandelion*." |
| dungeon, hollow | the dungeon entrance, every puzzle state kept | "Pip woke up at the entrance." |
| crown (finale) | the stage restarts at its start; it cannot fail (CANON §9.3) | "Pip woke up on the bough." |
| Dream | back in the parent realm beside the napping boss; the Dream simply ends | "Pip woke up beside the napping {boss}." |
| variant | its arrival spawn | "Pip woke up by the {spawn name}." |

**Falling off the world** (Driftholm, the Starmeadow, the Crown, a dungeon pit): never damage. "The clouds bounce Pip
back": he is placed on the last grounded position held for ≥ 1.0 s, 0.6 s fade, no toast after the first time per
realm ("The clouds bounced Pip back!").

<a id="realm-tod"></a>

### Time of day per realm

`S.tod` is one global clock. Realms with a frozen `tod` render at that time but do not change `S.tod`; leaving them
resumes the clock where it was. Interiors keep the clock running so schedules stay true. The Starsong's *Dusk* and
*Dawn* tunes ([items](#tool-starsong)) are the only way to jump the clock, and only at a bench outside a fight.

<a id="variants"></a>

### Variant realms

A variant is the **same World** as its parent (same seed, same generator, so its prints deep-equal the parent's) with
a different skin. `REALMS[id] = { kind: 'variant', variantOf, skin }`. The skin is data only:

| Skin field | Meaning |
|---|---|
| `palette` | fog table, sky stops, sun/moon, hemisphere, 7 terrain layer keys, water colours |
| `scatterRemap` | prop and deco type → replacement type (same footprint, same collider) |
| `hide` | prop types not drawn (and their colliders off) |
| `enemies` | the variant's spawn table (or `none`) |
| `npcs` | NPC set and spots (replaces the parent's) |
| `music`, `ambience` | track ids ([art-audio.md#music](./art-audio.md#music)) |
| `post` | one variant post-pass on its own RNG `new RNG(seed * k + c)` (constants in [atlas-home.md#passes](./atlas-home.md#passes)) |
| `tod` | frozen time |
| `exit` | the exit portal id and its paired parent spawn |

| Variant | Entered by | Skin summary | Enemies | Exit |
|---|---|---|---|---|
| **The Remembered Isle** (`remembered`) | `[E] Touch · Memory` at a lit knot on the Taproot (Rootdeep); 12 knots, each starts its memory scene | sepia and gold `#e9d8b0` `#b8894a` `#6f5a44`; Lamplighter beacons on every landmark; scaffolds on the Tree; young cast ([cast.md#young-cast](./cast.md#young-cast)); music box | none | the same knot shape at the spawn, `[E] Touch · Memory` ("Let the memory go"); also auto-offered when the memory scene ends |

## Portals

A portal is an anchor in `W.portals`:

```js
{ id: 'home:rootdoor', x, z, r: 1.2, to: { realm: 'nook', spawn: 'door' },
  how: 'use' | 'walk' | 'climb' | 'sail' | 'touch',
  verb: 'Enter', name: 'Pip\'s Nook',            // prompt `[E] Enter · Pip's Nook`
  needs: 'flag:wennaAwake',                       // condition; hidden (no prop, no prompt) until it holds
  locked: null | { needs, say },                  // shown but refused: `say` is the line, e.g. "Nell won't risk the fog yet."
  bundle: 'under_roots' }                         // PWA bundle to cache when the portal is first seen
```

- `how: 'use'` shows a prompt; `'walk'` triggers on entering the radius while grounded (a 1.0 s hold-off after
  arriving through it, so Pip is never bounced back); `'climb'` is a walk-in at the top of a climb;
  `'sail'` opens the chart; `'touch'` is a memory knot.
- A portal whose `needs` fails is invisible and not interactable. A portal whose `locked.needs` fails shows the prop
  and says `locked.say` on Use.
- The first time a portal is **seen** (within 40 m and in view), the service worker is asked to cache its bundle.
- Every portal has a paired spawn on the other side, on walkable ground, checked by the realm suite.

## The save plan

One save slot, key `starseed-isle-save-v2` (LOCKED). `js/save.js` stays a pure module: `freshState`, `MIGRATIONS`,
`migrate`, `normalize`, `loadSave`. Rules that every version follows:

1. One `SAVE_VERSION` bump + one `MIGRATIONS[n]` step + tests from **every** older version (v2-v(n)) per schema change.
2. **No v6 field moves or changes meaning.** `seeds`, `chests`, `bosses`, `plushies`, `rematches`, `secrets`, `errands`,
   `shells`, `visited`, `shopHeart`, `ending`, `coins` keep their v6 meaning for ever (`ending` = the bloom).
3. Before running any migration, `game.js` copies the raw stored string to `starseed-isle-save-v2-bak` (one copy,
   overwritten by the next migration, never read by the game except by "Restore backup" in Settings → Save).
4. `normalize` drops what it cannot validate instead of failing; a garbage field never stops Continue.
5. Expected size at 100 %: 40-80 KB. S-196 and S-309 assert it stays **under 80 KB**.

## Conditions and effects

`js/cond.js` (pure, S-025) is the one language every content table uses for "when" and "then". Content never calls
game code to decide what is unlocked.

**Conditions.** A condition is a string, an array of conditions (all must hold) or `{ any: [...] }` (one must hold).
`null` or `[]` always holds. Whitespace is not allowed inside an atom.

| Atom | Holds when | Example |
|---|---|---|
| `flag:<key>` | `S.flags[key]` is `true` or a non-zero number | `flag:wennaAwake` |
| `!flag:<key>` | it does not | `!flag:moteNamed` |
| `flag:<key>>=<n>` / `<=` / `=` | the flag's number compares (true counts as 1, absent as 0) | `flag:tide:archwater=1` |
| `item:<id>` / `item:<id>>=<n>` | `S.items[id] ≥ 1` / `≥ n` | `item:lantern`, `item:spoon>=5` |
| `!item:<id>` | not owned | `!item:chart` |
| `ability:<id>` | `S.abilities[id]` | `ability:glide` |
| `quest:<id>>=<n>` | the quest is at step n or later, or done | `quest:mq-ch8>=2` |
| `quest:<id>=done` | the quest is done | `quest:ss-07=done` |
| `quest:<id>.active` | started and not done | `quest:ss-10.active` |
| `seeds>=<n>` | Starseeds **placed** (`S.seeds[x] === 2`) | `seeds>=3` |
| `seedsHome>=<n>` | Starseeds carried or placed (`≥ 1`) | `seedsHome>=2` |
| `beacons>=<n>` | count of `beacon:*` flags (0-4) | `beacons>=3` |
| `stones>=<n>` | count of `stone:*` flags (0-3) | `stones>=2` |
| `lanterns>=<n>` | crown lanterns lit (0-8), see [Crown lanterns](#crown-lanterns) | `lanterns>=4` |
| `boss:<key>` | `S.bosses[key]` | `boss:whistlehollow:mossmantle` |
| `collect:<kind>>=<n>` | count of keys in `S.collect[kind]` | `collect:acorn>=50` |
| `secrets>=<n>` | keepsakes found | `secrets>=4` |
| `realm:<id>.visited` | any `visited` key of that realm, or `chart:<id>` | `realm:kettle.visited` |
| `in:<realm>` / `in:<realm>.<region>` | Pip is in that realm (and region) now | `in:home.village` |
| `met:<npc>` | shorthand for `flag:met:<npc>` | `met:nell` |
| `tod:<band>` | the band now: `day`, `dusk`, `night`, `dawn`; `\|` joins bands | `tod:dusk\|night` |
| `hour>=<h>` / `hour<<h>` | game hour now (0-24, decimals allowed) | `hour>=21`, `hour<23` |
| `sword>=<n>` | `S.swordLevel ≥ n` | `sword>=2` |
| `gems>=<n>` | `S.coins ≥ n` | `gems>=250` |
| `ending` / `mainEnding` / `trueEnding` | the bloom (v6 `S.ending`) / `flag:mainEnding` / `flag:trueEnding` | `ending` |
| `act>=<n>` | derived act: 1 until `flag:ch7`, 2 until `flag:act2done`, 3 until `flag:act3done`, 4 until `flag:mainEnding`, 5 after | `act>=3` |

**Effects.** An array of strings applied in order by `apply(S, effects)`; it returns the list of events to emit.

| Effect | Does | Allowed on |
|---|---|---|
| `set:<key>` / `set:<key>=<n>` | sets a flag to true / to a number | any flag in the registry |
| `inc:<key>` | adds 1 to a numeric flag | `counter` flags only |
| `toggle:<key>` | 0 ↔ 1 | `toggle` flags only (tides) |
| `give:<item>` / `give:<item>*<n>` | adds to `S.items`, capped at `stack`; plays the item-get beat if `ITEMS[id].beat` | any item |
| `take:<item>` / `take:<item>*<n>` | removes | `consumable` and `delivery` items only (buns, potions, parcels, Stair Stones placed, the seed planted) |
| `gems:+<n>` | adds gems, "+N gems!" floater | any; negative only from a shop |
| `heart` | `maxHp += 2`, `hp = maxHp`, the shipped container toast | containers only |
| `ability:<id>` | grants an ability | tools only |
| `quest:<id>.start` / `.next` / `.done` | quest progress | any quest |
| `collect:<kind>:<key>` | marks a collectible | the collectible's own pickup |
| `travel:<key>` | marks a bench, gate or chart node | travel anchors |
| `scene:<id>` | queues a scene | any |
| `toast:<textId>` | shows a feed toast (✿ prefix for good news) | any |

**Nothing earned is taken back** (tone rule 7): there is no effect that clears a story, `gate:` or `seen:` flag, takes a
tool, a key item that was a reward, a collectible or gems outside a purchase. The content lint fails an effect that
would.

**The flag registry.** `js/content/flags.js` exports `FLAGS`, one entry per exact key or per family pattern:
`{ key: 'moteNamed', kind: 'story', setBy: 'II.M', doc: '...' }`, `{ key: 'seen:*', kind: 'seen' }`. Kinds:
`story` (true, set once), `family` (a namespaced pattern), `seen`, `counter` (number, only increases), `toggle` (0/1),
`choice` (a number picked once). `tests/content.test.js` fails on any condition or effect naming a key that matches no
entry, and on any `set:` of a `story` flag from two different places.

## Dialogue

`js/dialogue.js` (pure, S-032) picks what an NPC says; `ui.say` shows it. Text is never in code: every line lives in a
text table `js/text/en/<realm>.js` as `{ '<id>': 'text' }`, read through `t(id, vars)`. A realm's text table is a
dynamic `import()` loaded with the realm.

**Entry shape** (`js/content/dialogue/<realm>.js`):

```js
{ id: 'duskwick.granny_wick.chart', npc: 'granny_wick',
  when: ['flag:ch8', '!flag:beat:beacon1'],     // condition
  lines: ['cc.wick.chart.1', 'cc.wick.chart.2'], // text ids, shown in order (one box each)
  frame: 'default',                               // see frames below
  set: ['set:seen:cc.wick.chart'],                // effects after the last line
  once: false,                                    // true → shown once, then `seen:<id>` blocks it
  priority: 40 }
```

**Picking.** `pick(npcId, S, ctx)` returns the highest-priority entry whose `when` holds (ties: the first in table
order). Priority bands:

| Band | Priority | Used for |
|---|---|---|
| Scene hand-off | 100 | a Talk that starts a quest step's scene |
| Main quest | 80 | the active main quest's line for this NPC |
| Count beat | 60 | a count-keyed line not yet seen (`once`) |

## Scenes

`js/scenes.js` (pure runner, S-034) plays a scene script; `cutscenes.js` owns the runtime (camera, poses, input lock).
The authoring format with examples is restated in [story.md#scene-format](./story.md#scene-format); this is the
runner's contract.

**Scene shape:** `{ id: 'I.6', realm: 'home', when: [...], trigger: {...}, skippable: true, replay: true,
steps: [...] }`.

**Step types:**

| Step | Fields | Does |
|---|---|---|
| `shot` | `cam: 'fp' \| 'orbit' \| 'fixed'`, `at: [x,y,z]`, `look: [x,y,z] \| actorId`, `fov`, `t` (blend s) | moves the camera; `fp` returns to Pip's eye |
| `say` | `who` (npc id or `wenna`/`mote`), `line` (text id), `frame` | one dialogue box; waits for {interact} |
| `wait` | `t` | waits t seconds |
| `pose` | `who`, `pose` (`idle`, `sit_dizzy`, `hold_out`, `wave`, `bow`, `sleep`, `cheer`, `look_up`), `t` | plays a pose on an actor |
| `move` | `who`, `to: spotId \| [x,z]`, `speed` (default 1.6 m/s) | walks an actor along an A* path |
| `face` | `who`, `to` | turns an actor |
| `spawn` / `despawn` | `who`, `at` | places or removes a scene actor (e.g. Mote) |
| `flag` | `set: [...]` (effects) | applies effects; **no-op in replay** |
| `emit` | `ev`, `data` | emits an event; **no-op in replay** |
| `fade` | `to: 0 \| 1`, `t` | fades the screen |
| `card` | `lines: [textIds]` | a full-screen card (act cards); waits for any button |
| `music` | `track`, `fade` | switches music; `null` restores the realm's track |
| `sfx` | `id` | plays a sound |
| `fx` | `id`, `at` | a one-shot effect (streak, leaf fall, beacon flare) |
| `sky` | `set: { windows, ladder, flights }` | forces sky overlay states for the shot; restored after |

**Triggers:** `{ on: 'talk', npc }`, `{ on: 'enter', realm, region | area: [x,z,r] }`, `{ on: 'flag', key }` (a flag
just set), `{ on: 'count', what: 'beacons', n }`, `{ on: 'tod', band, realm, area }` (e.g. I.6 at the first dusk in
the village), `{ on: 'item', id }`, `{ on: 'boss', key }`, `{ on: 'continue' }` (fires on Continue when its `when`
holds; I.6's "on Continue after dusk").

**Rules.** A scene never starts during a fight, a boss intro, a realm swap, a modal, or while Pip is airborne or in
the water's edge state; it waits in a queue of at most 2. Input is locked while it plays. Hold {interact} 1.0 s to skip
(a ring fills round the prompt); skipping applies every remaining `flag`/`emit` step at once, so skipping never loses
progress. On finish: `set:scene:<id>`. `replay(id)` plays it again from the journal's Lore tab with every `flag`,
`emit` and `spawn` of persistent actors suppressed. Every scene is replayable (tone rule 8) except tutorials.

## Quests

`js/quests.js` (pure, S-036). A quest is data:

```js
{ id: 'mq-ch8', n: 8, kind: 'main', realm: 'duskwick', title: 'qt.ch8.title', owner: 'granny_wick',
  start: 'flag:ch7',                       // condition: becomes active (auto) or offered (side: on Talk)
  steps: [
    { id: 'arrive', text: 'qt.ch8.s1', target: { realm: 'duskwick', spawn: 'jetty' },
      done: 'realm:duskwick.visited', on: 'REALM', hint: ['ht.ch8.s1.n', 'ht.ch8.s1.a'] },
    { id: 'meet', text: 'qt.ch8.s2', target: { npc: 'granny_wick' }, done: 'met:granny_wick', on: 'TALK_END', hint: [...] },
    ...],
  reward: ['give:chart', 'gems:+0'], set: ['set:ch8'], journal: 'qj.ch8' }   // `set` applies on done
```

- **Kinds:** `main` (one per chapter or isle; ids `mq-*`), `side` (`ss-01` … `ss-53`), `activity` (`act-*`, steps
  are tiers), `errand` (`errand-clover`, `errand-ribbit`: read-only adapters over v6 `S.errands`; never migrated).
- **Numbers `n`:** main 1-99 in chapter order, side 101-153 (`ss-NN` = 100 + NN), activities 201-212, errands 301-302.
  `n` is what the `track` flag stores.
- **Advancing.** The `quests` module listens to `TALK_END, ITEM_GET, KILL, CHEST_OPEN, REALM, PUZZLE, BOSS_DEFEATED,
  BEACON, STONE, COLLECT, SCENE_END, GATE, FISH, SKETCH` and calls `advance(S, event)`: for each active quest, if the
  current step's `on` matches (or is omitted) and its `done` holds, move to the next step (several in a row if they all
  hold). A step can never be failed. The last step applies `reward` and `set`, marks `'done'`, emits `QUEST`, and shows
  "✿ {title}" in the feed (side: "✿ Side story done: {title}").
- **Objective line and compass.** `objective(S, realm)` returns, in order: (1) the active **main** quest's current step
  if its target is in this realm or reachable from it; (2) the **tracked** quest (`track`); (3) today's rules
  (`hud/nav.js` fallback, e.g. "The isle is blooming ✿"). The compass points at `target`: `npc` (its current scheduled
  spot), `spawn`, `[x,z]`, or `realm` (the nearest exit leading there: jetty, root-gate or portal). The short label is
  the step's text id with `.short`.
- **Side quests** start on Talk with their owner (priority-40 entry with `quest:ss-NN.start`), never by walking past.
  None has a fail state; none gates a main quest (tone rule 9).
- **Lint** (S-036/S-038): every step has `text`, `done` and a two-part `hint`; every main quest has a chapter test; a
  quest's `start` cannot need a later act than its realm opens.

## Ask the Tree (hints)

Opt-in, two strengths, no penalty (research: the hint line in two strengths is the kindest form).

- Every quest step has `hint: [nudgeId, answerId]`. The lint fails a **main** quest step without both.
- In the journal's quest detail, **Ask the Tree** shows the nudge in a small leaf card (a leaf flutters down, 0.8 s).
  The button then reads **Ask again** and shows the plain answer, and the answer also drops the map marker on the
  step's target when it has one. Asking costs nothing and is not counted anywhere.
- **Voice:** Elder Shellby until `wennaAwake` (frame `default`, his portrait: "Hmm, let me think, dear..."); Wenna
  after (frame `wenna`), in every realm: "My roots reach a long way, little sprout." In the sky realms the leaf card
  says "A leaf drifts up on the wind..." before her line.
- **Nothing active?** With no active main step in reach, Ask the Tree names the land with the emptiest
  [completion](#completion) row group the player can reach now ("There's a lot still sleeping on Threemills.") and
  never a specific collectible. Collectible-finding help is the finders' job (the Acorn Ear and the Chime Bell,
  [items](#items-tools)) and the Completion page's region lines ([completion](#completion)).
- Hint text rules: the nudge names a place or a person, never a button sequence; the answer may name the tool and the
  object ("Ring the Tide Bell at the tide stone by the Raft").

<a id="tool-lantern"></a>

#### Lantern

Its light is one slot of the existing 4-light point-light pool, reserved while lit (no new lights, no
shader recompiles). In FP the bud glows at the bottom-left of the view; in TP Pip holds it out. A dark mouth refuses
entry without it: "Too dark to see. A light would help." (`locked.say`). The Bright Wick upgrade only changes the
radius.

<a id="tool-glider"></a>

#### Glider

`player.mods.gravityK` and `airCap` hooks (S-048); in FP the leaf's rim shows across the top 12 % of the
view; the glide breaks on landing, on Swing, or on releasing Hop. A gap gate is any span over 4 m between walkable
ledges marked `gap` by a finds pass, so the solver knows the Glider opens it.

<a id="tool-tide"></a>

#### Tide Bell

Rising water makes cells unwalkable; if Pip stands on one, he is lifted to the nearest walkable cell
over 0.5 s, bobbing (no swimming). Ringing away from a tide stone plays a chime and does nothing.

<a id="tool-hook"></a>

#### Thistle Hook

The vine line is a 1-draw tube. The target bloom shows a lilac ring when in range and in view. In FP
the aim is the crosshair; in TP the view centre.

<a id="tool-sunglass"></a>

#### Sunglass

The beam is a 1-draw additive quad from the Lantern to the first collider or 18 m. Mirrors
([dungeons.md#entities](./dungeons.md#entities)) turn 45° per sword hit and redirect it.

<a id="tool-mitts"></a>

#### Digging Paws

Soft earth shows a brown mound with a sparkle; the Chime Bell also chimes for buried chests.

<a id="tool-starsong"></a>

#### Starsong

Song mode shows three notes on a stave above the HUD tool slot; wrong tunes just play. At a bench outside a
fight, *Dusk* sets the clock to 19:48 and *Dawn* to 07:12 with a 2 s fade. *Calling* at any shore within 6 m of the
sea in an overworld with a jetty opens the chart as if at the jetty ("Nell heard you!"); in the Glassway it brings the
*Dandelion* to the nearest docking spot. Not in dungeons except where a room uses notes.

<a id="tool-sling"></a>

#### Ember Sling

Ember seeds light braziers and melt ice walls (3 hits) and wax plugs (1 hit). Against enemies it is
a 1-damage poke that never staggers bosses unless their def says so ([creatures.md](./creatures.md)).

<a id="tool-gloves"></a>

#### Ivy Gloves

Ivy lattices are box faces with a climb normal; the climb is a fourth movement state with the camera
kept off the wall by the spring arm.

<a id="tool-cloudstep"></a>

#### Cloudstep

A puff of cloud under Pip's feet at the second hop (FX only); no held model.

## Abilities and the progression solver

`js/abilities.js` (pure, S-048): `ABILITIES { id: { name, from: itemId } }` and `has(S, id)`. Ids: `lantern`,
`glide`, `tide`, `hook`, `sunglass`, `dig`, `starsong`, `sling`, `climb`, `cloudstep`, plus derived `sword2`
(`swordLevel ≥ 2`), `sword3` (`≥ 3`) and `boat` (`flag:ch14`). Getting a tool item applies `ability:<id>` in the same
effect list. Movement abilities change the player only through data hooks (`player.mods.gravityK`, `airCap`,
`extraHop`, `climb`), never by editing `player.js` logic per tool.

**The progression solver** `js/progress-graph.js` (pure; S-048, whole graph S-108):

- **Nodes:** each realm's reachable regions (a land may split into "zones" behind gates, each zone a node).
- **Edges:** portals, chart sailing, root-gates, benches, boat lanes, the Starstair, each with `needs` (a condition).
- **Items:** every find, tool, quest reward and story flag placed at a node with `needs`.
- **Run:** from a fresh save, repeat until nothing changes: take every reachable item whose `needs` holds, apply its
  effects (tools give abilities, quests set flags), open edges. Then:
  1. every main quest completes, in act order;
  2. **pacing rule 6:** each Act II isle's critical path (its `mq-*` steps) needs only `lantern`, `sword` and its own
     tool; each Act III place's critical path needs only Act II tools, `dig` and its own tool; a dependency on a
     sibling land's tool fails with the path that caused it;
  3. every chest, keepsake, acorn, vista, petal, bottle, Lamp Log, Hollow, bench and NPC is reachable in the final
     state;
  4. **pacing rule 5:** every tool opens ≥ 1 home find and every land re-opens ≥ 3 finds in earlier lands.
- **Report:** `bun test` prints, per ability, the finds it opens per land (the "what each tool opens" table that the
  close-out steps paste into DESIGN.md).
- **Failure cases** in the fixture suite: a soft-locked key, a sibling-tool path, an unreachable chest.

## NPC schedules

`js/schedule.js` and `js/pathfind.js` (S-174, ENGINE F27). Per-character schedules are data in [cast.md](./cast.md)
(each character's "schedule" field); this is the system they plug into.

**Format.** `SCHEDULES[npcId] = [[fromHour, spotId, activity], ...]`, sorted by hour, wrapping at 24. A spot id is a
realm anchor in `W.npcSpots` (`home:plaza_bench`, `home:cottage_hazel:in`), placed by the atlas files' post-passes.
Activities: `stand`, `wander` (within 4 m of the spot), `sit`, `sleep` (indoors only), `work` (a looped pose), `walk`
(path only, no stop), `fish`, `read`, `sweep`.

**Movement.** A* on `W.walk` (1 m cells, 8-neighbour, string-pulled), at most one path query per frame (queued), walk
speed 1.6 m/s (Granny Mochi and Grandpa Dormy 1.0 m/s, kits 2.2 m/s). An NPC whose target spot is in another realm
(e.g. indoors) walks to the door, fades out and is placed at the indoor spot. Off-screen NPCs (more than 60 m away or in
another realm) jump straight to where the schedule says they should be: no simulation.

**Rules.**
1. **Shipped spots are protected.** From 07:12 to 19:48 (day and dusk) the six LOCKED villagers stand at their shipped
   spots (Shellby (−3.8, 6.4), Ribbit (−11, 3.5), Miso (13.2, 13.0), Clover (0.7, 56.0), Hoot (4.3, −61.6), Digby
   (−103.1, −3.3)) so shipped hints, tests and `test:playthrough` stay true. Evening and night spots are new.
2. **Quest pins win.** While a quest step targets an NPC (`target.npc`), the NPC stays at the step's `pin` spot (or its
   current spot) regardless of the clock, so nothing is missable.
3. **Night is visible, never locked.** At night home villagers are indoors; knocking at their door (`Knock · {Name}`)
   lets Pip into their interior, where they talk in their sleepy lines. Grandpa Dormy is awake only 21:00-23:00
   (two game hours = 40 s of play); the Starsong's *Dusk* at a bench, or waiting by his fire (`sit` on his chair skips
   the clock to 21:00 with a fade), makes that window reachable on demand.
4. **Towns only.** Schedules run in towns, interiors and on home; isle folk outside towns keep fixed spots unless
   their side story moves them.
5. **Tests switch them off.** `?noschedules` and `G.debug.schedules(false)` freeze every NPC at its day spot; the chapter
   harness and `test:playthrough` use it.

**Shared time bands** (most schedules use these four changes):

| Band | Hours | Typical activity |

| morning | 06:00-12:00 | work at the day spot |
| afternoon | 12:00-17:24 | day spot, or the side-story place |
| evening | 17:24-21:00 | a gathering spot (the plaza benches, the jetty, the bandstand once built) |
| night | 21:00-06:00 | indoors, `sleep` |

**Plaza visitors.** Four extra plaza spots `visitor:pinewhistle`, `visitor:archwater`, `visitor:threemills`,
`visitor:duskwick` fill as beacons are lit ([Beacons](#beacons)); after `moteNamed`, the three Catchers visit the

<a id="coverage-test"></a>

### The coverage test

Every overworld (CANON §5.1). Divide the grid into 40 × 40 m cells aligned to `−half`. A cell
is a **land cell** if it holds ≥ 160 walkable, reachable 1 m cells. Every land cell must pass one of:
(a) it contains a point-of-interest anchor (chest, cache, keepsake, acorn, vista post, Lamp Log, bottle, Hollow door,
bench, root-gate, portal, NPC spot, gate object, fishing spot, Dash start, landmark base); or
(b) it contains ≥ 12 m of authored path or bridge deck and a cell in its 3 × 3 neighbourhood passes (a); or
(c) a landmark of this realm is within 160 m of the cell centre with clear line of sight from 1.6 m above the cell's
highest walkable point (a "view").
And for the whole land: point-of-interest anchors ≥ land area / 1,250 m². The test prints the failing cells as a map
so the step's implementer can see where to add a find. Realms with a tide run it in both states.

**Content lint** (`tests/content.test.js`, S-025 onward): every id referenced by conditions, effects, dialogue, quests,
scenes, shops and portals exists; no duplicate ids across realms; every text id has text; ≤ 220 characters; known
`{tokens}`; `~` only for Miso, `!!` only for Kinako; every main quest step has `hint` with two parts; every `set:` of a
`story` flag has exactly one source; no effect takes back an earned thing; every manifest key named by a realm exists
or has a fallback; every asset key used by a realm carries `realm: <id>` in the manifest.

**Other unit tests:** `save.test.js` (every migration from every older version), `economy.test.js` (the ledger rules),
`docs.test.js` (S-001: every `bible/<file>#<anchor>` link in INDEX.md resolves to an `<a id>`), `stats.test.js`
(stats.js equals regeneration), `keys.test.js` / `padbinds.test.js` (the `tool` and `journal` actions), boss balance
tests (a careful bot wins ≥ 90 % in the boss's window from creatures.md#balance-targets losing ≤ 3 hearts; a never-dodging bot ≤ 50 %), A* fixtures (S-174).

**Performance checkpoints** (S-047, S-087, S-109, S-151, S-196, S-261, S-287, S-309): measure the fixed views in both
cameras, swap times, `genMs`, precache (core ≤ 30 MB, each bundle ≤ 2.5 MB) and save size (< 80 KB), fix what fails,
and record the numbers in `docs/roadmap/progress.md`.

## Decisions made here

CANON left these open; this file decides them. A later writer who needs a different answer changes it here first.

1. **Flag keys allow upper case**: `/^[A-Za-z0-9:_.-]{1,48}$/`, because CANON's milestone flags are camelCase
   (`wennaAwake`, `moteNamed`, `act2done`). S-003's issue must use this regex, not the lower-case one in its scope line.
2. **Realm ids** for every dungeon, optional dungeon, Hollow, Dream and interior (the [registry](#realm-registry)
   tables), and the Crown's seed **40297**.
3. **Frozen times:** the Starmeadow 0.92, the Crown 0.88, the Remembered Isle 0.70 unless a memory sets its own,
   Moonmere 0.00, the Hundred-Year Night 0.875, Hoot's Margins 0.50. Interiors keep the clock running; dungeons freeze.
4. **Where Pip wakes when dizzy** outside home (last bench, else arrival spawn; dungeon entrance; boat; a Dream simply
   ends beside the napping boss) and the toasts. Falling off a sky realm or into a pit is never damage: the last
   position grounded for ≥ 1.0 s.
5. **Benches** fast-travel within the current land only until `mainEnding`, then to any land; sitting heals fully and
   sets the dizzy wake spot. Home gets **4 benches**; per-land counts total **53**.
6. **Root-gates:** none in Driftholm or the Starmeadow; the Glassway's is on the Puffin Post islet; the Rootdeep's
   Taproot plaza is an eight-mouth hub; ch13 opens every visited land's gate at once.
7. **Chart node positions**, the Glassway's "reef" node to the south, and the fog-bank lines.
8. **The boat's numbers** (acceleration, turn rates, collision radius 1.8 m, shallow limit 0.6 m, cameras); nothing
   ever attacks the boat; the chart-stop fallback is 9 islet stops with a 3 s card.
9. **The tool ring and context-first tool use**: hold `tool` 0.35 s for a ring of the 7 equippable tools; a tap uses the
   tool the targeted gate needs, else the equipped one.
10. **The Starsong's notes and tunes**: Roll = low, Hop = mid, Swing = high; *Dawn* low-mid-high, *Dusk* high-mid-low,
    *Calling* mid-high-mid; note colours `#5a6ad8`, `#f2c45a`, `#ff8fb0`; *Dusk* → 19:48, *Dawn* → 07:12 at a bench;
